Como o banner e gerado

Um workflow do GitHub Actions roda todo dia, le as contribuicoes via API e regenera o SVG:

# .github/workflows/update-mario.yml
name: Update Mario Banner
on:
  schedule:
    - cron: "0 0 * * *"   # todo dia 00:00
  workflow_dispatch:
jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Generate Mario SVG
        run: npx tsx scripts/generate-mario.ts ${{ github.repository_owner }} ...
Dica: o banner tem variante clara e escura (?theme=dark) e se adapta ao tema do GitHub via a tag <picture>.
